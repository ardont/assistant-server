## 1. История Запросов и Эволюция Системы

### Этап 1. Сохранение API-ключа и выбор рабочей модели
- **Запрос пользователя:** Сохранить переданный ключ Google Gemini API и проверить работоспособность.
- **Действия:**
  - Ключ надежно сохранен в защищенный файл `C:\HomeServer\config\.env` под переменной `GEMINI_API_KEY`.
  - Установлено, что модель `gemini-2.5-flash` возвращает 404 (Google требует актуальную модель `gemini-3.6-flash`).
  - Система переведена на `gemini-3.6-flash`, интеграция успешно протестирована.

### Этап 2. Сетевой доступ и общий доступ к папке INBOX
- **Запрос пользователя:** Открыть доступ к папке `INBOX` по локальной сети Wi-Fi для ноутбука и телефона без ручных настроек.
- **Действия:**
  - Определен локальный IP сервера: `192.168.50.108` (и Tailscale VPN: `100.110.6.52`).
  - Настроены права NTFS: `icacls "C:\HomeServer\inbox" /grant "*S-1-1-0:(OI)(CI)F" /T`.
  - Создан батник на Рабочем столе: `ENABLE_NETWORK_SHARE.bat` (`ОТКРЫТЬ_СЕТЕВОЙ_ДОСТУП_INBOX.bat`) с автоматическим повышением прав (UAC) для создания сетевой папки `\\192.168.50.108\INBOX`.
  - Подготовлена подробная инструкция для подключения с любого другого ноутбука (Проводник ➔ `\\192.168.50.108\INBOX`).

### Этап 3. Умный органайзер файлов с ручным подтверждением и защитой от случайных перемещений
- **Запрос пользователя:**
  - Просмотр предложений Gemini по сортировке файлов.
  - Файлы **не должны** перемещаться автоматически без явного согласия пользователя.
  - Кнопка физического удаления файла и предложения (`[🗑️ Удалить]`).
  - Кнопка отката перемещенного файла обратно во входящие (`[↩️ Вернуть в INBOX]`).
- **Действия:**
  - Реализован `C:\HomeServer\scripts\tasks\file_ai_organizer.py`.
  - Все новые файлы получают статус `pending` (ожидает решения).
  - Реализованы эндпоинты `/api/approve`, `/api/delete`, `/api/revert`.

### Этап 4. Защита персональных данных (Privacy Shield - DLP)
- **Запрос пользователя:** Обеспечить обезличивание чувствительных данных (паспорта, карты, контакты, договоры) перед отправкой в облачную LLM.
- **Действия:**
  - Разработан модуль `C:\HomeServer\scripts\core\privacy_shield.py`.
  - Локально на сервере (до выхода в интернет) маскирует:
    - Паспорта РФ ➔ `[ПАСПОРТ_РФ]`
    - Банковские карты (с проверкой алгоритмом Луна) ➔ `[БАНКОВСКАЯ_КАРТА]`
    - Номера телефонов РФ/СНГ ➔ `[ТЕЛЕФОН]`
    - Email-адреса ➔ `[EMAIL]`
    - СНИЛС, ИНН, банковские счета (20 цифр) ➔ `[СНИЛС]`, `[ИНН]`, `[БАНКОВСКИЙ_СЧЕТ]`
    - Секретные API-ключи и токены ➔ `[СЕКРЕТНЫЙ_КЛЮЧ]`
  - Протестировано на документе аренды — все данные успешно замаскированы, Gemini проанализировал документ без утечки PII.

### Этап 5. Интеграция с Календарем и Почтой
- **Запрос пользователя:** Автоматическое извлечение дедлайнов и событий из документов и синхронизация с телефоном.
- **Действия:**
  - Реализован RFC 5545 iCalendar поток: `http://192.168.50.108:8000/api/calendar.ics`.
  - Подписка в Apple Calendar, Google Calendar, Outlook в 1 клик.
  - Модуль отправки email через SMTP в `notifier.py`.

### Этап 6. Менеджер процессов, скриптов и живой терминал
- **Запрос пользователя:** Возможность запускать программы, ботов и скрипты с просмотром live-логов и метрик.
- **Действия:**
  - Создан `C:\HomeServer\scripts\core\process_manager.py`.
  - Асинхронный запуск, остановка процессов, стриминг логов в реальном времени.
  - Парсинг метрик `[METRIC:key=val]` в графические дашборды.
  - Написаны раннеры: `crypto_runner.py` (мониторинг крипты) и `backup_runner.py` (создание бэкапа).

### Этап 7. Диалоговый ИИ-Ассистент с долгосрочной памятью
- **Запрос пользователя:** Общий диалоговый чат с ИИ, который помнит пользователя, цели (ШАД, Python, крипта, финансы) и умеет создавать/изменять события в календаре.
- **Действия:**
  - Создан `C:\HomeServer\scripts\core\chat_agent.py`.
  - Подмешивание профиля пользователя (`user_profile.json`), текущих событий календаря и локального времени в контекст Gemini.
  - Автоматическое выполнение действий из текста:
    - Создание/удаление событий в календаре (`[ACTION:CREATE_EVENT]`, `[ACTION:DELETE_EVENT]`).
    - Запуск скриптов (`[ACTION:START_TASK]`).
    - Обновление памяти (`[ACTION:UPDATE_PROFILE]`).

### Этап 8. Мобильная адаптация, PWA и Умная декомпозиция задач
- **Запрос пользователя:**
  - Убрать отвлекающие вещи (очки опыта, серии).
  - Починить нажатия и скачивание файлов на Android (Honor).
  - Возможность скачать приложение в виде файла `.apk` прямо из вкладки «Файлы».
  - Разбить сложные цели на конкретные микро-задачи (по 15–20 минут) с уведомлениями на телефон.
- **Действия:**
  - Создан модуль умного планирования `C:\HomeServer\scripts\core\study_planner.py`.
  - Сгенерирован и загружен APK приложения в `C:\HomeServer\data\archives\HomeServer_Android_App.apk` (9.90 MB) для прямого скачивания.
  - Исправлен обработчик скачивания на сервере (устранена ошибка 403 с регистрозависимыми путями Windows).
  - Настроена мгновенная отправка утреннего фокуса в шторку телефона через `ntfy.sh` (тема: `homeserver_user_2026`).

## 2. Структура Каталогов и Ключевых Файлов

```
C:\HomeServer\
├── config\
│   ├── .env                      # API-ключи (GEMINI_API_KEY), SMTP, NTFY_TOPIC
│   ├── user_profile.json         # Профиль пользователя, проекты и правила сортировки
│   └── tasks_registry.json       # Реестр фоновых задач и скриптов
│
├── data\                        # Иерархический архив файлов
│   ├── documents\               # Документы, PDF, учебные материалы (ШАД и др.)
│   ├── code\                    # Исходный код, репозитории, скрипты
│   ├── spreadsheets\            # Таблицы, финансовые отчеты, Excel, CSV
│   ├── media\                   # Изображения, видео
│   └── archives\                # Архивы, бэкапы и HomeServer_Android_App.apk
│
├── inbox\                       # Входящая папка для новых файлов
├── backups\                     # Резервные копии сервера (.zip)
├── calendar_events.json          # События и дедлайны календаря
├── daily_plan.json               # Текущий микро-план на день и прогресс
├── chat_history.json             # История диалога с ИИ
├── inbox_proposals.json          # Предложения Gemini по сортировке
│
├── scripts\
│   ├── main.py                   # Единая точка входа 24/7 (uvicorn + планировщик)
│   ├── web_server.py             # FastAPI бэкенд и API эндпоинты
│   ├── dashboard.html            # Минималистичный веб-интерфейс
│   ├── manifest.json             # PWA манифест для мобильных
│   ├── sw.js                     # Service Worker
│   ├── icon.svg                  # Иконка приложения
│   │
│   ├── core\
│   │   ├── privacy_shield.py     # Локальный DLP-модуль обезличивания персданных
│   │   ├── chat_agent.py         # Диалоговый ассистент с памятью и вызовом функций
│   │   ├── study_planner.py      # Декомпозиция задач и генератор плана
│   │   ├── process_manager.py    # Управление фоновыми процессами и стриминг логов
│   │   └── notifier.py           # Push-уведомления (ntfy) и Email (SMTP)
│   │
│   └── tasks\
│       ├── file_ai_organizer.py  # Умный анализ файлов через Gemini 3.6 Flash
│       ├── crypto_runner.py      # Монитор криптовалют
│       └── backup_runner.py      # Создание zip-бэкапа сервера
│
└── venv\                        # Виртуальное окружение Python
```

| Сервис | Адрес | Описание |
|---|---|---|
| **Веб-интерфейс (Дома по Wi-Fi)** | `http://192.168.50.108:8000` | Доступ с телефона Honor, ноутбука, планшета |
