## 📖 О проекте

**HomeServer Multi-Channel AI Hub** — это серверная операционная среда и AI-помощник, работающий 24/7 на вашем локальном компьютере или сервере (Windows 10/11, Linux, macOS). Проект объединяет передовые языковые модели (**Google Gemini Flash, DeepSeek, локальные модели**), мессенджеры (**ВКонтакте, Telegram, MAX**), веб-панель управления и набор автономных инструментов автоматизации.

---

## ✨ Ключевые возможности и функции

### 🤖 1. Мульти-Мессенджер AI Хаб (VK, Telegram, MAX)
- **ВКонтакте Бот (Long Polling):**
  - Поддержка интерактивных кнопок и меню быстрых команд.
  - Автоматическая транскрипция голосовых сообщений на лету.
  - Прием документов и файлов прямо в папку `inbox/` с запуском автоматической AI-сортировки.
  - Умная отправка файлов, архивов драйверов и сервисных штрихкодов.
  - Автоматический обход ограничений групп (Error 912 fallback).
- **Telegram & MAX Боты:** Полноценная поддержка параллельной работы во всех мессенджерах из одного процесса.

### 🛡️ 2. Privacy Shield (DLP — Data Loss Prevention)
- Все входящие и исходящие тексты перед отправкой во внешние LLM автоматически очищаются локальным фильтром.
- Маскируются: персональные имена, телефонные номера, банковские карты, адреса электронной почты, внутренние IP-адреса локальной сети и токены доступа.

### 🧠 3. Изолированная долговременная память и профили
- Персональная память для каждого пользователя (`config/memory_<username>.json`).
- Автоматическое извлечение фактов из диалога («Запомни: ...», цели, предпочтения).
- Режимы работы: **Стандартный**, **🎓 Наставник**, **👑 Мультиагент**, **🕵️ Инкогнито** (без записи истории).
- Учет расхода токенов и гибкая система квот.

### 👑 4. Иерархическая Мультиагентная Команда
- **👑 Team Lead:** Декомпозирует сложные цели пользователя на пошаговые технические этапы.
- **🛠️ Tech Lead:** Разрабатывает техническую архитектуру и подбирает необходимые инструменты.
- **⚡ Executor:** Автономно выполняет шаги (поиск в сети, скачивание файлов, написание кода, создание ZIP-архивов, запуск команд).
- **🔍 QA / Reviewer:** Проверяет артефакты и формирует структурированный финальный отчет.

### 📓 5. Cloud Code & NotebookLM Research Engine
- **Source Grounding:** Глубокий анализ загруженных файлов (PDF, TXT, MD, код) без галлюцинаций.
- **Генерация артефактов знаний:**
  - 📑 **Briefing Doc:** Сжатые аналитические выжимки.
  - ❓ **FAQ & Study Guide:** Методические руководства и вопросы для самопроверки.
  - 🎙️ **Audio Overview Podcast Script:** Сценарий живого диалога двух ведущих для аудио-подкаста.
- **Cloud Code Runner:** Безопасный запуск и валидация скриптов анализа данных (Pandas, NumPy, Matplotlib).

### 📚 6. Динамические навыки (Skills System)
- Каталог специализированных скиллов с авто-установкой (`pip`, создание `SKILL.md`):
  - 💼 `1c-enterprise-integrator` — Настройка сканеров 1С, COM-портов, Честного Знака.
  - 🌐 `web-scraper-automation` — Парсинг маркетплейсов и каталогов.
  - 🖥️ `windows-sysadmin-optimizer` — Оптимизация служб, RAM, RDP, сети и PowerShell.
  - 📓 `cloud-notebooklm-researcher` — Аналитика, синтез документов и запуск кода.

### 📥 7. Автоматический AI-Органайзер INBOX
- Фоновое сканирование входящей папки `inbox/` (доступной по SMB-сети `\\192.168.x.x\INBOX`).
- AI-анализ содержимого файлов и автоматическое перемещение в `data/documents`, `data/code`, `data/spreadsheets`, `data/media`, `data/archives`.

### 🎓 8. Проактивный AI-Ментор
- Фоновый таймер с тремя суточными слотами:
  - 🌅 **Утренний старт:** Проверка плана на день, мотивация, предложение материалов.
  - ☀️ **Дневной чекап:** Вопросы по прогрессу и устранению блокировок.
  - 🌙 **Вечерняя рефлексия:** Подведение итогов дня и сохранение инсайтов в память.

### 🖥️ 9. Веб-Панель Управления и Центр Безопасности
- **Главный Dashboard (`/`):** Интерактивный AI-чат, файловый менеджер, просмотр логов, запуск задач, аналитика памяти.
- **Админ-панель (`/admin`):**
  - Управление пользователями, ролями и правами доступа.
  - ✏️ **Редактирование, привязка и удаление VK ID** для любого пользователя в один клик.
  - ⚙️ **Глобальная настройка параметров VK Bot** (`VK_BOT_TOKEN`, `VK_GROUP_ID`, `VK_USER_ID`) прямо из браузера.
  - Установка лимитов и квот на токены AI.
  - Генерация инвайт-кодов для регистрации.

### 🌐 10. Доступ отовсюду (24/7)
- **Localhost:** `http://localhost:8000`
- **Локальная сеть / Wi-Fi:** `http://192.168.x.x:8000`
- **Tailscale VPN:** Защищенный приватный IP `http://100.x.x.x:8000`
- **Cloudflare Tunnel:** Автоматический внешний публичный HTTPS-домен без выделенного IP и без проброса портов.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/ardont/assistant-server.git
cd assistant-server
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение Python:
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Настройка конфигурации
Создайте файл `config/.env` на основе шаблона:
```bash
cp .env.example config/.env
```
Откройте `config/.env` и укажите:
- `GEMINI_API_KEY` — API-ключ Gemini (из Google AI Studio).
- `VK_BOT_TOKEN` и `VK_GROUP_ID` — ключ доступа и ID сообщества ВКонтакте.
- `VK_USER_ID` — ваш числовой VK ID для авторизации доступа к боту.

### 4. Запуск сервера

#### В Windows:
Дважды кликните по файлу **`start_homeserver.bat`** или выполните в консоли:
```cmd
python scripts\main.py
```

#### В Linux / macOS:
```bash
python scripts/main.py
```

После запуска в консоли отобразятся доступные адреса для подключения:
- 💻 **Web UI:** `http://localhost:8000`
- 🌐 **Внешний HTTPS (Cloudflare):** `https://xxxx.trycloudflare.com`

## 🔒 Безопасность

1. **Никаких секретов в коде:** Файлы `.env`, базы пользователей, токены сессий и персональные архивы надежно исключены через `.gitignore`.
2. **Пароли:** Хранятся с использованием стойкого хэширования **SHA-256 с индивидуальной солью (salt)**.
3. **Белый список VK / Telegram:** Бот принимает команды только от пользователей, чей ID явно указан в `.env` или привязан в базе данных администратора.
